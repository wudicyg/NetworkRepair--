# Roadmap

当前最新正式发行版：`v1.4.0`；当前主线开发基线：`1.5.0-dev`。维护者确认 Windows 10 实机矩阵已通过。Windows 11 未实机验证，明确暂缓，不列为当前适配任务或发布阻塞项。

## v0.1.x — 稳定基础层
- [x] 模块化 PowerShell 架构
- [x] Safe Repair
- [x] 自动备份
- [x] 验证与自动回滚
- [x] JSON 报告
- [x] Pester + GitHub Actions
- [x] 发布验证只读证据采集器
- [x] Windows 10 核心实机验证（历史编号 Profile 清理路径）

## v0.2.x — 更智能的诊断
- [x] Network List Manager COM 枚举
- [x] Profile 与活动 Network List 对象交叉验证（基础版）
- [x] 风险评分与可解释原因
- [x] DNS / DHCP / 默认网关诊断
- [x] NCSI DNS / HTTP 诊断
- [x] 统一诊断代码

## v0.3.x — 更完整的修复能力
- [x] 安全网络名称重命名
- [ ] 目标化 Signature 清理
- [x] 更精细的服务刷新策略
- [x] 多级恢复点

## v0.4.x — 用户体验
- [x] 修复决策/操作计划层
- [x] 网络健康与 Profile 历史遗留双轨判定
- [x] Safe Repair 执行进度与最终结果反馈
- [x] TUI 菜单增强（只读快速状态概览）
- [x] GUI 前端（WinForms）
- [x] 一键导出脱敏诊断包
- [x] 自动更新检查（只检查与告知，不自动替换自身）

## v1.0.x — 稳定发布
- [x] 1.0.0 核心实机验收（Windows 10）
