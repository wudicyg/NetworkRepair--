# Diagnostic Codes

| Code | 含义 |
|---|---|
| NR0000 | 未发现明显问题 |
| NR1001 | 发现疑似历史/重复 Profile |
| NR1002 | 当前活动连接使用了编号 Profile，禁止自动删除 |
| NR1003 | 发现 Managed Profile，禁止自动修改 |
| NR2001 | DNS 解析测试失败 |
| NR2002 | TCP/443 连通性测试失败 |
| NR3001 | 修复前备份失败 |
| NR3002 | 修复操作失败 |
| NR3003 | 修复后验证失败 |
| NR3004 | 自动回滚失败 |
